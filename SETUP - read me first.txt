SID'S SORTING CENTER - SETUP (about 5 minutes)
==============================================

Tracks Pokemon Center parcels from your Gmail and Royal Mail, with Discord alerts.

1. INSTALL PYTHON (once)
   - Go to https://www.python.org/downloads/windows/ and install Python 3.
   - In the installer, TICK "Add python.exe to PATH", then click Install Now.

2. PUT THIS FOLDER SOMEWHERE SAFE
   - Unzip it, e.g. into Documents, so you have Documents\SIDs Sorting Center\

3. START IT
   - Double-click "Start SID's Sorting Center.bat".
   - The first time it sets itself up (about a minute), then the app opens.

4. ENTER YOUR OWN DETAILS (Settings tab opens by itself the first time)
   - IMAP email: the Gmail address that gets your Pokemon Center emails.
   - App password: make one at https://myaccount.google.com/apppasswords
     (needs 2-Step Verification on). Paste the 16 letters. It is saved in
     Windows Credential Manager, never in a file. The app only READS email.
   - Discord: in your server, Server Settings > Integrations > Webhooks >
     New Webhook > Copy Webhook URL, paste it in. (Optional.)
   - Press "Test IMAP login", then Save. Tracking starts on its own.

5. NICE EXTRAS (Settings)
   - "Create desktop & Start menu shortcut" for a Poke Ball shortcut.
   - "Start with Windows" so it runs in the background (system tray).
   - Look & pictures: add your own pictures for the header and alerts.
   - Phone view: press Copy and open the link on your phone (same Wi-Fi).
   - Updates: it checks for new versions every day and installs them itself
     (or press "Check for updates now"). Your settings are kept.

If something goes wrong, the launcher window stays open and shows why,
and details are in error.log in this folder.
